# Hayali Zaman Yolcusu Eğitmeni

## UYARI: BU PROJE ULUSLARARASI ZAMAN YOLCULUĞU KURULU TARAFINDAN ONAYLANMIŞTIR (Onay numarası: 42-YZ-∞)

Merhaba değerli zaman yolcusu adayı!

Bu depo, hayali zaman yolcularını profesyonel seviyede eğitmek için tasarlanmış **en gelişmiş**, **en bilimsel** ve **en absürt** simülasyon sistemidir. Gerçek zaman yolculuğu yapabileceğinizi **garanti etmiyoruz**. Hatta hiçbir şey garanti etmiyoruz. Ama gülme krizine girme ihtimaliniz %99.7'dir (bilimsel olarak ölçülmüştür, kaynak: içimizden geldi).

### Özellikler
- Zamanı 3 saniye ileri/geri sarma (gerçekten! `time.sleep` ile)
- Hayali paradoksları çözme antrenmanı
- "Keşke dün o böreği yemeseydim" pişmanlık simülatörü
- Gelecekten gelen mesajlar (aslında rastgele üretiliyor)
- Tamamen Türkçe arayüz (çünkü evrensel dil Türkçe'dir, kanıtlanmamıştır)

### Kurulum
```bash
git clone https://github.com/Tentivory/hayali-zaman-yolcusu-egitmeni.git
cd hayali-zaman-yolcusu-egitmeni
python zaman_egitmeni.py
```

### Kullanım
Programı çalıştırın. Size sorular soracak. Cevaplarınızı ciddiyetle verin. Sistem sizi değerlendirecek ve "Zaman Yolcusu Sertifikası" basacaktır (ekrana yazdırarak).
